## 📋 Pasos Realizados (Resolución de la Consigna)

### 1. Creación del Repositorio en GitHub
- Se ingresó a la cuenta de GitHub ([https://github.com/Neun211](https://github.com/Neun211)).
- Se creó un nuevo repositorio público con el nombre exacto solicitado:

- Se abrió GitHub Desktop (o terminal Git) y se clonó el repositorio en la computadora:
  ```bash
  git clone https://github.com/Neun211/UTN-TUPaD-Programacion1.git
  ```

- Se copiaron dentro de la carpeta del repositorio local los archivos de las prácticas anteriores (como `condicionales.py`, prácticas de secuenciales, etc.).

- Se prepararon los archivos y se realizó el commit con un mensaje descriptivo:

- Se enviaron los cambios al servidor remoto de GitHub:
  ```bash
  git push origin main
  ```
